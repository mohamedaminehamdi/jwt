Jobs API
Endpoints API reference GitHub

Track every job application behind one token.

Jobs API is a Node.js and MongoDB REST API for job hunting. You register, log in and get a JSON Web Token. Every request after that carries it, so each person only ever sees their own applications.

View the code Read the API reference

Send it on every jobs request as Authorization: Bearer <token>. Hover a part of the token to see what it holds.

Endpoints

Everything lives under /api/v1. Requests and responses are JSON, and errors come back as { "msg": "…" } with a matching status code.

Open to everyone
POST/auth/registerCreate an account and get a token
POST/auth/loginLog in with email and password, get a token
GET/healthCheck that the server is up
Needs a Bearer token
GET/auth/meSee your profile
PATCH/auth/meChange your name, email or location and get a fresh token
GET/jobsList your applications with filters, search, sorting and pages
POST/jobsAdd an application
GET/jobs/statsCount applications by status and by month for the last six months
GET/jobs/{id}Get one application
PATCH/jobs/{id}Edit an application
DELETE/jobs/{id}Remove an application

Find the right application

The list endpoint takes query parameters you can combine. It returns { jobs, totalJobs, numOfPages }.

GET /api/v1/jobs?status=interview&jobType=remote&search=engineer&sort=latest&page=2&limit=10
status
Where the application stands, or all.
pendinginterviewdeclined
jobType
full-time, part-time, remote, internship or all.
search
Matches the position, ignoring case. Special characters are treated as plain text.
sort
latest, oldest, a-z or z-a by position.
page and limit
Pages start at 1. The limit is 10 by default and can go up to 100.

Run it locally

You need Node.js 18 or newer and Docker. The app and the API docs open on port 3000.

  1. Get the code

    git clone https://github.com/mohamedaminehamdi/JWT.git
cd JWT && npm install

  2. Set a secret

    cp .env.example .env

    Then put a long random string in JWT_SECRET.

  3. Start it

    docker compose up --build

    Open localhost:3000 for the web app and localhost:3000/api-docs for Swagger. Run the tests with npm test.

What's inside

Security

  • Passwords hashed with bcrypt and never returned
  • Login and register limited to 100 requests per 15 minutes
  • Helmet headers and CORS
  • Query operators stripped so {"$ne": null} logins fail
  • Request bodies capped at 10 kB

Tooling

  • 36 tests with the built-in node:test runner against real MongoDB
  • GitHub Actions on Node 18 and 20
  • Dockerfile and Compose with MongoDB 6
  • OpenAPI 3 spec served with Swagger UI
  • Plain JavaScript web app with no build step
